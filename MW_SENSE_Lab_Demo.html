One expandable monitoring path

Monitor temperature, relative humidity, relative VOC index and soil moisture with one ESP32 node. Validate readings locally before sharing them through a common wireless data format.

WHY THE ESP32

Edge processing plus wireless connectivity

The microcontroller reads digital and analog inputs, checks data quality, prepares a JSON packet and sends it using WiFi. A centralized dashboard can support additional nodes later.

What is verified and what is not

The component names, GPIO choices and sampling rules follow the supplied Tinkered project. The animated environment, network buffering, historical records and second virtual node are browser teaching models. They are not proof of physical sensor accuracy, radio reliability or live MQTT delivery. The presentation circuit uses different example pins. For this website the Tinkered pin map takes priority.
